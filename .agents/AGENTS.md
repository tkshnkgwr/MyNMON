# AI Agent Instructions for MyNMON

本プロジェクトにおける大賢者の開発指示書です。
最優先ルール（コミット禁止・テーブル整列等）は [[GEMINI.md]] を参照してください。

## 🎯 開発・品質ルール

- **技術解説方針（他言語経験への配慮）**:
  - ユーザーは他言語での開発経験をお持ちですが、Rust固有の専門用語（所有権、トレイト、ライフタイム等）には不慣れです。
  - 難解な用語をそのまま多用せず一般的プログラミング概念に置き換えるか直感的な解説を添えて報告してください。
- **コミットメッセージ**:
  - コミットを行う際は、プレフィックス（`feat:`, `fix:`, `chore:` 等）を除き、コミットメッセージ本文は**日本語**で記述すること。
- **事前検証とドキュメント同期**:
  - 開発およびドキュメント更新の際は、必ず [`docs/ja/INSTRUCTIONS.md`](../docs/ja/INSTRUCTIONS.md) に記載されている「対象ドキュメント一覧と更新ルール」および「品質管理・事前検証プロセス」に厳格に従って検証・同期を行うこと。
  - **※Markdownファイル（`.md`）のみの修正時は、Rustの事前検証（`cargo fmt` / `cargo check` / `cargo test` 等）は省略し、迅速に対応すること。**
- **コード規模とリファクタリング**:
  - 単一のプログラムソースファイル（例: `src/*.rs`）の行数が **1,000 行** を超えた時点で、関心事・役割に応じたモジュール分割リファクタリングを検討・提案すること。
